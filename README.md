# Omnifood

A fully responsive HTML/CSS landing page built as part of Jonas Schmedtmann's
course on Udemy.

The link of the built project is: https://effervescent-kulfi-8c876e.netlify.app/

---

## Purpose

This project documents my transition into web development before migrating fully
into ML engineering. It demonstrates working knowledge of modern HTML/CSS layout
techniques — flexbox, CSS Grid, responsive design — which underpin the frontend
components in later projects.

---

## What it covers

- Semantic HTML5 structure
- CSS custom properties and a consistent design system (spacing, typography, colour)
- Flexbox and CSS Grid layouts
- Fully responsive design across mobile, tablet, and desktop (media queries at 5 breakpoints)
- Sticky navigation with IntersectionObserver
- Smooth scrolling and mobile hamburger navigation via vanilla JavaScript
- Safari flexbox gap polyfill

---

## Stack

HTML · CSS · Vanilla JavaScript

---

## Run locally

No build step required. Open `index.html` directly in a browser.
